# Security policy

| Версия | Поддерживается |
| ------ | -------------- |
| `main` | да             |

## Как сообщить об уязвимости

Если ты нашёл уязвимость, **не открывай публичный issue**. Напиши на адрес, указанный в `package.json` репозитория владельца, или открой `Security advisory` через GitHub:

`Repository → Security → Advisories → Report a vulnerability`.

Что включить:

- Краткое описание (что и где).
- Шаги воспроизведения или минимальный proof-of-concept.
- Возможный impact (раскрытие данных, RCE, DoS и т. д.).
- Версия / коммит, на котором воспроизводится.

Я отвечу в течение **3 рабочих дней** и подтвержу получение. Дальше — координированный disclosure: договоримся о сроке фикса (обычно ≤ 14 дней для high-severity) и публикации.

## Что считается уязвимостью

- Утечка PII кандидатов через логи, API-ответы, PDF или Sheets.
- Возможность скрытого обхода `ADMIN_USER_ID` и вызова админских команд.
- Уязвимости в зависимостях (npm) с уровнем `high` / `critical`.
- Возможность бесконтрольной записи в Google Sheets третьим лицом.
- Injection-векторы через input кандидата (SQL/NoSQL/command/template).

## Что **не** считается уязвимостью

- Любое поведение, требующее физического доступа к серверу.
- Запуск без `TELEGRAM_BOT_TOKEN` / `GROQ_API_KEY` / `GOOGLE_*` — бот логирует warning и продолжает работу с урезанным функционалом.
- Rate-limit, который можно обойти с **множества** разных `user_id` — это design trade-off, защита от спама с одного пользователя.

## Меры безопасности в коде

- **Secrets никогда не коммитятся.** `.env` в `.gitignore`, `.env.example` содержит только имена переменных.
- **PII-редакция в логах** через `redactPii` в `src/format.ts` — имена/handle маскируются до stdout.
- **`MarkdownV2` экранирование** через `escapeMd` — не даём кандидату сломать форматирование сообщения админу.
- **`UNIQUE (candidate_tg, vacancy_id)`** — один кандидат не может затопить вакансию повторными интервью.
- **Rate-limit `/start`** — 5 нажатий в минуту на user_id через Redis `INCR`/`EXPIRE`.
- **Параметризованные запросы** через `pg` — никакого ручного `query` без `$1`.
- **`zod` валидация env** в `config.ts` — бот не стартует с битой конфигурацией.
- **Dependabot** — еженедельные алерты по npm, ежемесячные по GH Actions и Docker.
