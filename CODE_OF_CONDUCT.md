# Code of Conduct

Этот проект следует упрощённой версии [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## Правила

- Будь уважителен. Критика идёт по коду и решениям, не по людям.
- Конструктивный тон, без сарказма в адрес автора PR / issue.
- Никаких личных атак, оскорблений, троллинга, преследования.
- Никакой публикации чужих личных данных без согласия (контакты, рабочие email и т. д.).
- Сексуализированный язык, изображения и провокации недопустимы.

## Зона действия

Кодекс применяется в репозитории (issues, PR, обсуждения, ревью) и в любых публичных каналах, где обсуждается проект.

## Reporting

Если ты столкнулся с нарушением — открой приватный security advisory или напиши автору напрямую (контакт в `package.json` / профиле). Все обращения рассматриваются конфиденциально.

## Меры

В зависимости от тяжести — предупреждение, временный бан на участие в обсуждениях, постоянный бан. Решение принимается мейнтейнером.
